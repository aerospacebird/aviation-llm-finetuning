# Aviation system design

## 1. 목적

이 프로젝트는 항공산업 전반에서 실제 업무에 쓰일 수 있는 도메인 특화 LLM을 설계하는 데 목적이 있습니다. 특히 조종사와 항공사 운영 인력이 비행 중 빠르게 확인할 수 있는 단기 답변형 AI를 구현합니다.

## 2. 핵심 요구사항

- 항공 규정, 비행 절차, 지상/항공 운영 문서와 연계
- 낮은 지연시간 응답
- 잘못된 비행 절차 추천 방지
- 문서 근거 기반 응답
- 금융/리스크 요인과 항공 운영 문맥 연결

## 3. 아키텍처

1. Data layer
   - 문서 정리, OCR, 매핑, 정책 문맥화
2. Training layer
   - Llama base model + LoRA/QLoRA fine-tuning
3. Retrieval layer
   - RAG 기반 문서 검색
4. Safety layer
   - 규정 확인, 위험 판단 금지, 출력 제한
5. Serving layer
   - CPU/GPU/NPU 배포 전략 분리

## 4. 운영 전략

- GPU: 대형 학습 및 실시간 추론
- NPU: 경량 보조 모델 및 로컬 추론
- CPU: 검증, 테스트, 배치형 처리

## 5. 평가

- 문서 근거성
- 안전성
- 정확성
- 응답 속도
- 비상 절차 우선순위

## 6. 실무적 제약

실제 항공 운영에 임베딩할 때는 반드시 항공사 내부 문서, 규정, 안전 검증, 책임소재 검토가 선행되어야 합니다.
