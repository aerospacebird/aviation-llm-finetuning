# 항공 특화 LLM 운영 워크플로우

## 1. 비즈니스 목표

- 조종사가 비행 중 필요한 정보를 빠르게 확인할 수 있는 LLM 생성
- 항공 규정, 안전 절차, 항공사 SOP, 기상 정보, 리스크 문맥을 통합하여 체계적 응답 제공
- 금융/운영/정비 문서와 항공 절차를 연결하는 지식 기반 모델 설계
- 하드웨어별 최적화: CPU, GPU, NPU 환경에서 일관된 응답 품질 확보

## 2. 핵심 구성 요소

1. 문서 ingestion layer
   - PDF, TXT, Markdown, Excel, JSONL 등 처리
   - 문서 정합성 검증 및 메타데이터 기반 인덱싱

2. 도메인 정제 layer
   - 항공 용어 표준화
   - 규정/절차 문맥 분류
   - 중복 문서 제거 및 신뢰도 점수 부여

3. 모델 training layer
   - Llama base model
   - QLoRA/LoRA 기반 파인튜닝
   - instruction tuning + safety tuning

4. RAG & retrieval layer
   - 문서 chunking
   - 의미적 검색
   - 출처 기반 응답 구성

5. Safety & governance layer
   - 허용/금지 문맥 규칙
   - 비행 절차 관련 추정 제한
   - 항공 내규 검증 요구

6. Serving layer
   - CPU: 로컬 검증, 디버깅
   - GPU: 대형 추론
   - NPU: 경량 온디바이스 추론

## 3. 운영 원칙

- 비행 중은 빠른 참조형 응답만 허용
- 모든 비상 절차 응답은 문서 근거 기반으로 제한
- 금융/리스크 분석은 별도 모델 또는 RAG subgraph로 분리 고려
- 한국어/영어/다국어 문서 통합 지원

## 4. 실험 로드맵

1. 기초 문서 데이터 수집
2. 도메인 데이터셋 정제
3. LoRA 학습
4. RAG 고도화
5. 안전 필터 검증
6. NPU 경량 배포
7. 실무 인프라 통합

## 5. 거버넌스

- 실제 항공 운영 적용 전 승인 절차 필요
- 내부 규정, 안전, 보안, 라이선스 검토 필수
- 환각 최소화, 응답 기록 보관, 인간 검토 프로세스 적용
